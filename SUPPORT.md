# Support

Thanks for using Vidyqor. Vidyqor is an open source Education ERP built on the
Frappe Framework. The project is currently at the **foundation / scaffold** stage —
the repository structure, build configuration, and documentation exist, but the
18 functional modules are **Planned** and not yet implemented.

## Where to get help

- **Questions and discussion** — open a thread in
  [GitHub Discussions](https://github.com/whoami4101/Vidyqor/discussions).
- **Bug reports** — file an issue with the bug report form at
  [GitHub Issues](https://github.com/whoami4101/Vidyqor/issues).
- **Feature requests** — file an issue with the feature request form at
  [GitHub Issues](https://github.com/whoami4101/Vidyqor/issues).
- **Security reports** — do not use public issues. Follow [SECURITY.md](SECURITY.md).

## Before you open an issue

1. Search [existing issues](https://github.com/whoami4101/Vidyqor/issues) and
   [discussions](https://github.com/whoami4101/Vidyqor/discussions) to avoid duplicates.
2. Read the [documentation](docs/) — start with
   [docs/getting-started/introduction.md](docs/getting-started/introduction.md).
3. Include your environment details (Frappe version, Python version, OS) and clear
   reproduction steps.

## Frappe Framework resources

Vidyqor builds on the Frappe Framework. For questions about Frappe itself, see the
[Frappe Framework documentation](https://docs.frappe.io/framework) and the
[Frappe community forum](https://discuss.frappe.io).
