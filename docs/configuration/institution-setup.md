# Institution Setup

> **Project status:** foundation / scaffold only. Everything below describes **Planned**
> behavior. No configuration screens or DocTypes exist yet.

Once the functional modules are implemented, this guide will walk through the first-run
setup an administrator performs after installing Vidyqor.

## Planned setup flow

1. **Create the institution profile** — name, type (school/college/university), address,
   and academic calendar. _(Planned — Institution Management module.)_
2. **Define the organizational structure** — departments and faculties.
   _(Planned — Department Management, Faculty Management.)_
3. **Configure academic settings** — programs, courses, terms, and grading schemes.
   _(Planned — Academic Management.)_
4. **Set roles and permissions** — map staff and faculty to roles.
   _(Planned — System Configuration; see [architecture/permissions.md](../architecture/permissions.md).)_
5. **Enable optional modules** — finance, library, hostel, transport, and others as needed.
   _(Planned.)_

## Current reality

None of the above is available yet. The scaffold registers the app and its 18 Planned
module folders, but there are no settings to configure. Follow the project roadmap in the
[README](../../README.md) for progress.
